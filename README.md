# Taste Veelicious

1. Push this folder to GitHub and import it in Vercel (framework: Other).
2. In the Vercel project: Storage > Create > Blob (Public). Connect it to the project. This adds BLOB_READ_WRITE_TOKEN.
3. Settings > Environment Variables: add ADMIN_PASSWORD (your own strong password).
4. Redeploy. Store is at /, admin panel at /admin.html.
